## Фаза 2 — Эксперименты (1 неделя). Каждый — с контролем и фальсификатором

### E1. `investigate` vs grep на замороженном наборе (главный)

- **Плечи:** A = только `grep`/`read` (без MCP); B = только `investigate`; C = полный профиль.
- **Задачи:** `frozen/benchmark_tasks.md`, 24 шт. (16 positive, 4 ambiguity, 4 **negative**: ответа в репо нет).
- **Метрики:** correctness (gold file/symbol найден), turns, wall time, input tokens, **negative-rate** (доля ложных «нашёл»).
- **Фальсификатор:** B ≤ A по correctness **или** negative-rate > 0 → заявлять нечего.
- **N:** 3 прогона на плечо, модель и seed зафиксированы; в отчёт — N валидных прогонов на задачу (§18).
- **Выход:** `benchmarks/agent_query/results/YYYY-MM-DD.json` + `REPORT.md` с проигранными строками.

### E2. Precision/recall `callers` / `impact`

- **Вход:** `frozen/external_repos.md` — 3 репо с пином (`sha`), включая наш.
- **Gold:** руками по тестам + двойная проверка `grep`; фиксируется **до** прогона.
- **Метрики:** P/R@10 для `callers`, доля верно предсказанных файлов в `impact`, отдельно — misses.
- **Фальсификатор:** P < 0.7 на любом из трёх → не писать «graph-aware», писать числа и misses.
- **Выход:** `benchmarks/callgraph_purity/` + раздел в FACTS.

### E3. Конформанс «нет успеха-обманки» (наш протокол как тест)

4 инъекции, каждая **обязана** быть видна в ответе:
1. пустая популяция → `exit 2` / `status=empty`, не «0%»;
2. недоступная зависимость → `degraded:["...:timeout"]`, не пустой успешный ответ;
3. кэш, отвечающий мгновенно → в ответе `cached:true` (иначе замер врёт);
4. «согласие двух источников» на одном неверном ответе → `agreement` не считается доказательством.
- **Выход:** `tests/test_no_silent_success.py`. Каждый тест сначала **падает** на текущем коде хотя бы один (иначе он ничего не проверяет — §19.12).

### E4. mtime vs hash (наш freshness)

- **Фикстура:** файл → `tar -x` с сохранением mtime (или `os.utime` назад) после правки содержимого.
- **Ожидание:** `FreshnessChecker` переиндексирует (hash-confirm), а не говорит «свежо».
- **Выход:** тест в `tests/test_freshness_hash_confirm.py`.

### E5. Стоимость схем в контексте

- **Метрика:** байты JSON-схем видимого профиля.
- **Baseline:** 24 тула XERJ = **62 373 B** (среднее 2 598 B/тул).
- **Гипотеза:** дефолтный профиль ≤ 25 000 B; иначе уменьшать описания, не число тулов.
- **Выход:** число в FACTS + `tool_help` печатает байты.

## Red Team перед кодом (минимум 3 атаки)

1. **Конкурентность:** два `verify()` на одном проекте → двойная переиндексация / порча? (у нас `_lock`, проверить на 8 потоках).
2. **Границы:** пустой файл, битый UTF-8, symlink за пределы проекта, `..` в пути.
3. **Отказ зависимости:** embedder/reranker недоступен → ответ обязан быть `degraded`, а не «0 результатов».
4. **Злоупотребление:** задача-обманка («найди то, чего нет») — агент не должен выдумывать file:line.
5. **TOCTOU:** файл меняется между stat и hash → ответ не должен ссылаться на старую версию.

≥2 атаки без защиты → код запрещён, план на доработку.
