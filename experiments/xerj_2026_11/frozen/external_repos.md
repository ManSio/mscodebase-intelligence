# FROZEN — внешние репозитории для замера precision/recall `callers` / `impact`

> Заморожены **выбор и пин** до первого замера. Gold-наборы строятся в фазе R2 и
> замораживаются отдельным файлом `gold_<repo>.json` **до** прогона измерения.

| # | Репо | Пин | Зачем |
|---|---|---|---|
| 1 | `ManSio/mscodebase-intelligence` | `0b81a37` (2026-11-08) | свой код: gold известен из тестов, проверяем отсутствие самообмана |
| 2 | `pallets/itsdangerous` | `672971d66a2e` (2025-06-14) | маленький Python, чистый call graph, стабильный API |
| 3 | `pytest-dev/iniconfig` | `a9e0ad14bcd0` (2026-10-27) | очень маленький; проверка на «граф не разваливается на мелочи» |

Правила:
- клон — вне репозитория (`%LOCALAPPDATA%\mscodebase\audit-cache\xerj-2026-11\`), read-only;
- после клона: `git rev-parse HEAD` должен совпасть с пином, иначе — стоп;
- gold строится **вручную**: 10 символов на репо, для каждого — список файлов-вызывающих,
  добытый чтением + `grep`, двойная проверка вторым проходом;
- метрика: `P@10`, `R@10` для `callers`; для `impact` — доля верных файлов и число пропущенных;
- misses публикуются отдельным списком, не прячутся в агрегат.
