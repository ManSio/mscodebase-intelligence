# Root Cause Evaluation — аудит предсказания root cause (инциденты)

**Назначение:** данные и скрипты для оценки качества root-cause предсказаний по инцидент-датасету.

**Статус:** 🟡 исследование (2026-07-22).

**Артефакты:**
- `evaluate_root_cause.py` — оценка предсказаний.
- `gold_standard.py` + `gold_validation.json` — золотой стандарт + валидация.
- `incident_dataset.json` / `incident_dataset_full.json` — датасет инцидентов.
- `evaluation_results.json` / `evaluation_output.txt` — результаты прогона.
