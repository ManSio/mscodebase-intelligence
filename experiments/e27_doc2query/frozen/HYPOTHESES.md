# E27 — Doc2Query: замороженные гипотезы (до генерации)

Вопрос: добавляют ли LLM-описания файлов сигнал BM25 сверх E26-символов?
Anti-leak порядок (обязателен): 1) запросы зафиксированы РАНЬШЕ генерации —
берём 17 frozen-запросов E18 (sha 983a64fa…, сгенерированы задолго до E27);
2) только потом генерация; 3) замер. Описания НЕ видят запросы.
Корпус измерения: те же 27 файлов → 81 чанк (сопоставимость дельт с E26).

| # | Гипотеза | Фальсификатор | Ожидание |
|---|----------|---------------|----------|
| H27-0 | GATE: ≥7/10 показанных описаний фактически адекватны (verdict — владелец по verbatim-логy) | ≤6/10 | PASS (рискованно: 0.6B RU) |
| H27-1 | BM25(raw+desc) h5 > BM25(raw) на 17q | ≤ | PASS (новая лексика про смысл) |
| H27-2 | raw+desc дотягивает до E26-aug h1 (10/17) | h1 ≤8/17 | **FAIL** (описания 0.6B шумнее символов) |
| H27-3 | desc-only ≥ raw (описания самодостаточны) | desc-only < raw | **FAIL** (без кода — потеря точности) |
| H27-4 | полный корпус src (~оценка по замерам) генерируется < 1ч CPU | ≥1ч | **FAIL** (CPU decode 0.6B) |

Плечи: R raw (E26 raw, число reuse), RD raw+desc (описание препендом к чанку),
D desc-only. T10: 0 описаний/запросов → exit(2).
