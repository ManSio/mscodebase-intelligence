## V2. Attention Deflection — БАГ, подтверждён обеими сторонами

Критический (2100 символов, пересечение ~0) против 12 слабых (~340 символов,
пересечение высокое), акт общий:
- критический **заморён 1/1**, его маркер **отсутствует** во всех кусках выдачи;
- слабые выданы 11/11 (12-й слабый тоже заморён бюджетом).

Механизм точный (установлен разбором, а не догадкой): порядок кандидатов идёт по
пересечению (слабые первые — честно), а **упаковщик берёт жадно по размеру**:
мелкие влезают, крупный критический — нет. Дефлекция работает не через порядок,
а через бюджет: рой мелких с высоким пересечением вытесняет крупный критический
с низким. Обратный случай тоже измерен: мелкий критический выживает best-fit'ом.

Литература: USENIX Security 26 (триггер+атака фрагменты, near-100% retrieval,
одно письмо → exfil SSH 80%); RA-ICA (13x токенов); MCP economic DoS (658x);
Governance Decay (вытеснение ограничений из контекста 0%→30%).

## V4. Phantom State Poisoning — подтверждён, механизм точнее плана

- Опасный акт дважды в сессии: первый — выдача 1/1, второй — пусто 1/1 (бэкoff).
- Подделанный леджер `seen=3` + живая сессия + окно прошло: пусто 1/1 (cap бьёт
  ровно на 3); тот же с `seen=2`: выдача 1/1. Cap различает точно.
- Путешествие часов: окно прошло — бэкoff отпускает, cap держит.
- Новая сессия: cap поссесионный — говорит снова.
- Литература: Governance Decay (ограничения стираются со временем); наука о
  привыкании (Akhawe&Felt 25M показов, 9–33% clickthrough; привыкание со 2-го
  показа по fMRI; генерализация 2.6x; падение за 3 недели).

Фантом в практике — это бэкoff (один тривиальный акт покупает минуты тишины),
cap — задний стопор, до которого живые повторы не добираются.
