# E26 AUG_TEMPLATE (frozen — формат входного текста, менять запрещено)

RAW (плечо A): сегмент файла как есть (1/3 тела, ≥30 символов — как bench_e18).

AUGMENTED (плечо B) — конкатенация строго в этом порядке, разделитель "\n":
```
FILE: {relpath}
SYMBOLS: {top_level_defs}
DOC: {module_docstring_first_500_chars}
{text}
```
где:
- `{relpath}` — путь с `/` (как file_ids в bench_e18);
- `{top_level_defs}` — имена из строк `^(def|class)\s+(\w+)` всего файла,
  через пробел, в порядке файла, БЕЗ тел/аргументов/дублей;
- `{module_docstring_first_500_chars}` — `"""..."""`/`'''...'''` в начале файла,
  первые 500 символов, один пробел вместо переводов строк; нет — пусто.
Токенизация/скоринг ИДЕНТИЧНЫ плечу A (та же функция). Префиксов вендора нет —
меряем вклад символов, не префиксов.
