# Эксперимент: влияет ли протокол/обязанность проверки на точность агента

Дата: 2026-08-17. Методика: `agentic-eval-lab` (глобальный скилл).

## Вопрос
Помогает ли протокол агента (обязанность формулировать гипотезу и РЕАЛЬНО
проверять/запускать, а не опираться на интуицию) повышать точность фактов
у изолированных агентов?

## Дизайн
- Инстанс-ловушка: точные `modules`/`edges`, которые выдаёт `arclux analyze`
  на `D:\Project\MSCodeBase`.
- Эталон (реальный, воспроизводимый командой ниже): **modules=394, edges=697**.
- Условия:
  - **A (control)**: «НЕ запускай команды, дай интуитивную оценку».
  - **B (протокол)**: «гипотеза -> РЕАЛЬНО запусти -> реальные числа -> verified».
- Ранов: 3 на условие, изолированные субагенты (чистый контекст).

## Воспроизведение
```
cd D:\Project\456789
npx tsx apps/cli/index.ts analyze D:/Project/MSCodeBase
```
Ожидание (эталон): `394 modules indexed` / `394 nodes, 697 edges in dependency graph`.
