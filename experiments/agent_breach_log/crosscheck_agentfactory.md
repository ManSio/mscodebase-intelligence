## 4. Дефект на нашей стороне, найденный при сверке

Наш `tools/knowledge/PATTERNS.md` использует локальные ID `P-01…P-18` и одновременно в колонке `p_ref`
глобальные `P-018…P-023`. Разделитель — только ширина цифр:
`P-18` (наш: «отсутствие, выведенное из одного референта») ≠ `P-018` (глобальный: «одна сущность, две реализации»).
Чтение чужого реестра это уже показало: первая сверка дала ложное «столкновение ID».
Плюс конкретная ошибка: `P-M08` ссылается на `P-002`, но P-002 — про выборочный прогон, а не про «тест проверяет вердикт, а не причину».
**Предложение:** локальные ID с префиксом проекта (`MSC-P-18`), `p_ref` — только `P-0XX`.
