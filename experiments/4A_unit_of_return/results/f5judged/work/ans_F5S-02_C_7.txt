Модуль `redact` ловит секреты по **структурному префиксу** (не по энтропии) — для каждого известного формата (AWS, OpenAI, GitHub, JWT и т.д.) есть свой compiled regex с жёстким началом вроде `AKIA`, `sk-ant-`, `-----BEGIN.*PRIVATE KEY-----`. Это **не граница безопасности**: он режет только известные формы на одной строке; новый формат, секрет, разбитый по строкам, или записанный словами — пройдёт дальше. Снижает цену случайности, но канал доставки остаётся небезопасным для credential.
