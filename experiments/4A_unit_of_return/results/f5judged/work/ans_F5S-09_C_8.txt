Система рассчитана на **6 уровней** деградации. Когда внешние провайдеры недоступны, система последовательно переключается вниз по цепочке: L1 llama.cpp GGUF → L2 ONNX INT8 (in-process) → L3 LM Studio → L4 BM25 (ключевой поиск) → L5 SymbolIndex (только AST-символы) → L6 ожидание индекса. При этом базовая функциональность сохраняется на каждом уровне.
