При недоступности PropertyGraph (`pg is None` или отсутствует путь к БД) gate возвращает пустой результат со статусом «unavailable» через `_empty(...)`, не пробрасывая исключение наружу. Поведение при git-сбое в данном контексте не показано — функция получает `diff_text` как входной параметр, а не вызывает git напрямую, поэтому обработка сбоя git происходит у вызывающего кода.
