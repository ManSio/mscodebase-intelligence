Возвращает пустой dict со статусом `"unavailable"` и никогда не бросает исключение наружу (`_empty("unavailable", ...)`): при `pg is None` → `"PropertyGraph not available"`, при отсутствии `db_path` → аналогично. Для git контекст явно не показан, но контракт функции — «никогда не бросает наружу», значит при любом сбое инфраструктуры — мягкий возврат пустого результата, не exception.
