Модуль ловит только **известные формы** по структурному префиксу (не энтропию) — AWS-ключи, JWT, Bearer-токены, URL с кредами, присваивания вида `API_KEY=<значение>`. Это **не граница безопасности**: новый формат, секрет, разбитый по строкам, или записанный словами — проходит, и код это прямо документирует (строки 11–13).
