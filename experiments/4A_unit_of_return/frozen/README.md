лежат **здесь** и **коммитятся**. Хранить их в `%TEMP%` / `/tmp` **запрещено**.

`e7_HANDOUT_EN.recovered.md` (write rid=75331, 2026-09-22; сверено с read rid=75864).

быть git-tracked (иначе CI падает).
