## Стабильность судьи

Непоголосовавшие (5 вердиктов не единогласны): **8/64 = 12.5%** — сопоставимо с Coin Flip Judge (~13.6% single-trial flip). Majority по 5 смягчает.

## Наблюдения (direction)

1. **B ≫ A для кода** (0.475 vs 0.075, CI не пересекаются): whole-doc единица даёт читателю **~6×** больше верных ответов, чем чанки. Объективный ретрив (F5 objective) при этом был A≈B — т.е. **единица возврата влияет на ЧИТАТЕЛЯ, а не на попадание gold-файла**.
2. **Для прозы A > B** (0.25 vs 0.125, CI пересекаются — слабо): длинный целый doc прячет ответ; чанки точнее.
3. **C (oracle) ≈ 0.95–0.975** — потолок высокий; разрыв C−B большой → место для лучшей единицы есть.
4. **D = 0** — без индекса читатель не отвечает (контроль работает).
