# ADR-0007 — Git-based файловые лока для параллельных агентов

**Status:** ACTIVE (2026-08-24)

## Context

2026-08-19 и 2026-08-24: две сессии параллельно коммитили в один `.git`
(одна — Live Sync, другая — линтер/предиктор). Симптомы: `index.lock`,
`cannot lock ref 'HEAD'`, чужие застейдженные файлы утащены чужим
`git add -A`-коммитом. Общий handoff-файл с таблицей статусов — advisory-lock
с гонкой TOCTOU (оба агента читают «свободно» и тихо теряют данные).

## Decision

Каждый лок — **отдельный файл** `.locks/<resource_id>.lock` (JSON:
resource/agent/acquired_at/purpose/estimated_duration_min), который агент
**коммитит и пушит** сразу. Атомарность гарантирует git: второй push на тот же
путь невозможен без pull → гонка видима и отклоняема. Реализация:
`scripts/lock_guard.py` (status/acquire/release), `.locks/README.md`,
advisory-вывод статуса в pre-commit хуке (exit 0 — не блокирует).

Правила: не редактировать файл с чужим активным локом; освобождать сразу;
stale-lock (>2ч без коммитов владельца) снимать ТОЛЬКО с явной причиной в
сообщении; статус — коммитами, не таблицей.

## Alternatives considered

- Общая markdown-таблица статусов — отклонена: TOCTOU, деградация до
  «последний пишущий побеждает» (что и случилось 19.08/24.08).
- Single-writer через OS-level файл-локи (`.git/index.lock` сам по себе) —
  недостаточно: git уже защищает index, но не защищает ОТ «sweeping»
  чужих staged-правок `git add -A`.
- Полная сериализация сессий (один окно-агент за раз) — нецелесообразно:
  параллельность — плановая возможность.

## Impact

- Плюс: гонки становятся видимыми на уровне git; чужую работу нельзя
  случайно закоммитить.
- Минус: для одиночной сессии лок не нужен (опционально); acquire = +1 коммит.
- Взаимодействие с CI: нет (locks не трогают раннеры).

## Consequences (Temporal)

- T+30d: правило «перед правкой проверить lock» должно войти в привычку
  агентов (чек-лист §10.7 скилла).
- T+180d: если гонок больше нет — locks становятся чистым ритуалом,
  пересмотреть нужность (это ок — коммиты-локи дешевле инцидентов).
