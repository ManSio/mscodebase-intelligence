# История версий

## [3.5.0] — 2026-11-08

> Перевод: 2026-11-08. Канон — [docs/en/CHANGELOG.md](../en/CHANGELOG.md); этот файл
> намеренно не дублирует английский текст.

История изменений ведётся в одном месте — `docs/en/CHANGELOG.md`, потому что записи
привязаны к коммитам и релизам, а не к языку интерфейса. Здесь — только указатель и
правила чтения.

| Что | Где |
|---|---|
| Полная история версий и breaking changes | [docs/en/CHANGELOG.md](../en/CHANGELOG.md) |
| Числа, которые разрешено цитировать | [docs/FACTS.md](../FACTS.md) |
| Открытый техдолг и наблюдения | [KNOWN_ISSUES.md](../../KNOWN_ISSUES.md) |
| Решения по архитектуре (ADR) | [docs/adr/](../adr/) |

Формат записей — Conventional Commits: `type(scope): описание`; breaking change
помечается `!` и абзацем `BREAKING CHANGE:`. Запись, которую нельзя проверить
командой из репозитория, в историю не попадает.
