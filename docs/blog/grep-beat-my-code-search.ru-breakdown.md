## 2. Почему этот сюжет

Из четырёх кандидатов выбран E68–E73, потому что:

1. **Не повторяет ни один из 12 постов.** В корпусе нет ничего про
   commit-localization, `abstain` и про то, что бенчмарк мерил политику, а не
   качество. Bootstrap Pipeline — про TESTS-рёбра, Unit of Return — про
   читателя. Это третья, свободная ось.
2. **Контринтуитивен в правильную сторону.** «Мой инструмент проиграл grep» —
   то, что читают и оспаривают: у тебя лучшие посты по комментариям (17 и 34) —
   именно там, где спорный тезис с числами.
3. **Полный нарратив:** гипотеза → провал → причина → два бага → планка, которую
   я сам поставил неверно. Финал не «победили», а «отрицательный результат
   остался в продукте».
4. **Не требует чужих данных** (в отличие от истории 313-МБ базы dev.to).

Отклонены: гейты (счёт тестов в дневнике гуляет 2560/2561/2564/2570/2607 против
2476 в `WISDOM.md` — пост про доверие числам на таком фундаменте сам себя
подорвёт); база dev.to (чужие данные); AgentFactory (одна цифра на весь пост).

## 6. Что поймала ред-тима (и что я исправил)

Свежий контекст, только черновик + первоисточники. Вердикт: **63 проверено,
15 не совпало, 2 выдумано, публиковать как есть нельзя.**

| Находка | Что было не так | Как закрыто |
|---|---|---|
| **blocker** Главная панель подана как чужой код | 174 коммита — это **твой** репозиторий (`REPORT.md:222` «this repo»); внешние только requests/sqlalchemy | переписан хук: три корпуса, и «grep won on both repos I did not write» |
| **blocker** Таблица не сходилась (19 против 19+7) | счётчики — это dev (n=71), а не все 108 | таблица подписана «dev split (n=71)» — теперь всё сходится |
| **blocker** «+16 of 37 на sealed» | 21 − 7 = 14; 16 — дельта против `search` | убрано, sealed больше не выдаётся за +16 |
| **blocker** «CI не пересекаются» | grep [0.57,0.89] и tool [0.23,0.59] касаются на 0.57–0.59 | переписано на «overlapping at 0.57–0.59» |
| **blocker** Триада 19/71 + 0/44 + 37/71 | разные панели и корпуса в одном предложении | разнесено: одна панель + отдельная негативная |

| **blocker** Планка P2 переписана | в спеке «+5 задач», не «не ниже» | цитата вердикта дословно, без пересказа |
| **major** «66 reference files» | 66 — это задачи | «66 tasks whose answer files…» |
| **major** «found no occurrence of any of them» | на момент E68 проверялся ПЕРВЫЙ токен | «the first identifier it extracted» |
