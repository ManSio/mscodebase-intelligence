# MSCodeBase Live Sync (VS Code)

Расширение передаёт изменения файлов (включая **несохранённые**) из VS Code в
демон MSCodeBase по WebSocket. Демон держит актуальный текст в RAM-оверлее →
поиск/индекс всегда свежие, без записи несохранённого на диск.

## Сборка и установка

```bash
cd extensions/vscode/mscodebase-sync
npm install
npm run compile
# В VS Code: F5 (Run Extension) — или скопировать папку в ~/.vscode/extensions
```

## Настройка (минимум, «из коробки»)

Расширение само определяет корень проекта (`workspaceFolders`), вручную путь
прописывать **не надо**. Настраиваются только адрес демона и токен:

| Настройка | По умолчанию | Назначение |
|---|---|---|
| `mscodebase.serverUrl` | `ws://127.0.0.1:8089/ws/sync` | URL демона (в домашней сети — адрес хоста) |
| `mscodebase.authToken` | `` | Bearer-токен (`MSCODEBASE_REMOTE_TOKEN` на демоне) |
| `mscodebase.debounceMs` | `350` | задержка отправки (защита от спама на каждую клавишу) |

## Протокол (WebSocket `/ws/sync`, JSON)

- `hello` → авто-регистрация проекта + ре-синк несохранённых буферов
- `change` → обновление RAM-оверлея (дебаунс + монотонная `version`)
- `save` / `close` → сброс оверлея + дебаунс-переиндексация
